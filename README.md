Descripción del sistema:
# Campomix

Sistema web desarrollado con **Python, Flask y MySQL** para gestionar materias primas, proveedores, almacenes, recepciones, productos, recetas, 
órdenes de producción, etc. Su objetivo es facilitar el control de inventarios, la planificación de la producción y ventas, centralizando la información en una plataforma sencilla y organizada.
